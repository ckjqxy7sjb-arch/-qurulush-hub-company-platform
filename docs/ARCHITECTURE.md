# Полный стек проекта "ДГАСК КР"

Проект переводится с HTML/Python-прототипа на рабочий full-stack контур:

- Frontend: React 18.3 + Vite 5, SPA, защищенные маршруты по ролям.
- Backend: Node.js 20 LTS + Express 4.19, REST API, слои routes -> controllers -> models.
- DB: PostgreSQL + чистые SQL migrations `001...007`, JSONB для гибких форм.
- Auth: JWT access token + refresh token в httpOnly cookie, bcryptjs, таблица отозванных refresh-токенов.
- Production: Windows Server, PM2, IIS reverse proxy.

Главная бизнес-логика новой версии: центр входящих уведомлений для строительной компании.

Пользовательский поток:

1. Компания получает уведомление из sacc2 / Минстроя / ДГАСК.
2. Директор или ответственный принимает уведомление в работу.
3. Система назначает задачу прорабу, бригадиру, бухгалтеру или юристу.
4. Бухгалтер оплачивает начисление и прикрепляет квитанцию.
5. Исполнитель загружает документ, фото или акт устранения.
6. Ответственный отправляет подтверждение обратно в ведомственный контур.
7. Вся история остается в журнале действий.

Из пользовательского интерфейса убираются:

- министерские демо-страницы;
- юридический справочник НПА как основной раздел;
- production readiness, launch bundle, acceptance evidence и env validators;
- фиктивные объекты, инспекторы и ведомственные demo-данные как основное содержимое.

Legacy-файлы пока остаются в репозитории как reference до окончательной миграции.
