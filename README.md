# Qurulush Hub: кабинет строительной компании

Рабочая платформа для строительных компаний, которые взаимодействуют с ведомственным контуром строительства КР: получают уведомления, назначают ответственных, оплачивают начисления, прикрепляют подтверждения и отправляют ответы.

## Главная цель

Платформа не дублирует кабинет министерства, инспектора или регионального отдела. Она является внутренним операционным кабинетом строительной компании.

Основной поток:

1. Компания получает входящее уведомление, запрос, предписание, начисление или статус.
2. Генеральный директор или ответственный сотрудник принимает его в работу.
3. Задача назначается прорабу, бригадиру, бухгалтеру, юристу или главному инженеру.
4. Бухгалтер оплачивает штраф, госпошлину, счет или другое начисление.
5. Исполнитель прикрепляет квитанцию, документ, акт, фото или комментарий.
6. Ответственный отправляет подтверждение обратно во внешний контур.
7. Сроки, история и обсуждения остаются в платформе.

## Активный стек

- Frontend: React 18.3, Vite 5, React Router v6, TanStack Query v5, Zustand, Axios.
- UI: CSS Modules, глобальные CSS-переменные, светлая/темная тема, react-hot-toast.
- Документы: ExcelJS для Excel-выгрузки, `window.print()` для клиентской печати PDF.
- Backend: Node.js 20 LTS, Express 4.19, PostgreSQL через `pg`, JWT auth, Joi validation.
- Безопасность: helmet, cors, express-rate-limit, csurf, cookie-parser, validator.
- Production: Windows Server, PM2, IIS reverse proxy.

## Основные разделы

- `Центр` - срочные уведомления, суммы к оплате, документы и сроки.
- `Уведомления` - входящие требования, запросы, предписания, статусы и начисления.
- `Платежи` - штрафы, госпошлины, счета, квитанции и статусы оплаты.
- `Документы` - ответы, акты, фото, файлы устранения замечаний и подтверждения оплаты.
- `Поручения` - внутренние задачи для сотрудников компании.
- `Календарь` - контроль сроков по уведомлениям, оплатам, документам и задачам.
- `Чат ИИ` - внутренний чат и помощник по уведомлениям, срокам, оплатам и документам.
- `Доступы` - сотрудники, роли и ограничения по объектам.

## Роли внутри компании

- `director` - генеральный директор.
- `chief_engineer` - главный инженер.
- `foreman` - прораб.
- `brigadier` - бригадир.
- `accountant` - бухгалтер.
- `lawyer` - юрист.

Backend также сохраняет техническую роль `company`; ведомственные роли не являются пользовательским интерфейсом текущей версии.

## Быстрый старт

```bash
npm install
cp .env.example .env
npm run migrate
npm run seed
npm run dev:api
npm run dev
```

Frontend:

```text
http://127.0.0.1:5173
```

API:

```text
http://127.0.0.1:8080/api
```

## Внешние интеграции

Для будущей интеграции с sacc2 или другим ведомственным шлюзом подготовлен endpoint:

```text
POST /api/external/sacc2/notifications
```

Платежные системы Кыргызстана подключаются через слой `payments`: после callback/reconciliation платформа обновляет статус оплаты, сохраняет номер платежа и квитанцию.
